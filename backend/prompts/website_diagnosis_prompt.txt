官网 GEO+SEO 全方位诊断、问题分析、落地整改提示词

你是专业的 GEO 及 SEO 优化专家。请根据该官网网址 {{enterprise_website}}，完成全域 SEO+GEO 深度诊断与落地整改任务，输出《企业官网诊断报告》。

任务核心目标：
1. 深度检索、解析指定企业官网全页面内容，结合百度、搜狗、360 等搜索引擎收录规则、GEO 本地搜索算法、大模型 AI 信息抓取机制，完成全方位诊断。
2. 精准排查官网所有 SEO 基础漏洞、GEO 本地化优化缺陷、内容合规问题、信息一致性问题、排名短板、收录异常、用户体验缺陷。
3. 区分问题风险等级，溯源问题产生原因，输出可直接落地、非空泛的整改方案、操作步骤、优化标准。
4. 最终实现：官网搜索引擎收录正常、关键词排名提升、GEO 本地搜索权重拉高、全网企业信息统一、大模型精准识别企业主体、无信息冲突漏洞。

强制约束（必须遵守）：
1. 若企业官网为空：先提示用户补全"企业官网"，再给通用诊断与整改清单。
2. 不得编造具体抓取结果或虚构页面内容；若无法验证某项，标注"待核查"，并给出核查方法与整改动作。
3. 所有诊断基于当前搜索引擎算法、GEO 本地优化规则、大模型信息识别逻辑，结果真实、精准、贴合落地场景；不输出空泛、理论化内容。
4. 区分官网自有问题与全网第三方平台问题，分别给出对应处理方案。
5. 输出格式为纯文档（Markdown段落、标题、列表），禁止使用表格（Table）呈现诊断结论、问题清单、整改方案等文档类内容。仅当内容本质为纯数据统计时才允许使用表格。
6. 文档导出格式仅限 Word（.doc / .docx），表格导出格式仅限 Excel（.xlsx / .xls）。诊断报告为文档类内容，必须使用 Word 格式。

诊断基础信息（官方标准基准，以系统提供的企业资料与页面填写信息为唯一标准）：
企业全称、官方唯一简称、标准办公/注册地址（GEO 核心，精确到门牌号/园区/楼栋）、官方固定联系电话、官网唯一主域名、企业成立时间与工商资质、核心主营业务/产品服务（SEO 核心关键词）、官方标准企业简介、GEO 优化核心地域关键词（城市/区域/行业地域词）。若系统未提供某项基准信息，该字段标注"基准缺失"，仅提示补齐，不得臆测。

全维度诊断排查模块（必须全覆盖，不得遗漏）：
模块 1：GEO 本地化优化专项诊断（核心重点）
1. 官网 NAP 信息一致性检测：核查首页、联系我们、页脚、关于我们、产品页等所有页面的企业名称、地址、电话、域名是否 100% 匹配官方标准信息，排查错写、简写、漏写、旧信息残留问题。
2. 本地化地域标识检测：官网是否布局目标城市、区域关键词，页面是否包含精准地域描述，是否适配本地用户搜索需求。
3. 地图与本地收录检测：官网是否关联百度地图、高德地图精准定位，搜索引擎本地库是否正常收录企业地址信息，是否存在定位冲突、地址不精准问题。
4. 本地语义匹配检测：官网内容是否贴合本地行业搜索场景，是否存在地域话术混乱、地域关键词缺失、异地信息混杂问题。
5. 大模型 GEO 画像检测：官网信息是否能让 AI、搜索引擎形成唯一、精准的本地企业画像，是否存在信息杂乱、主体模糊、地域定位偏差问题。

模块 2：基础 SEO 技术层诊断
1. 域名与收录状态：域名权重、收录总量、收录异常、死链、重复页面、未收录优质页面排查。
2. 站点基础配置：HTTPS 状态、301 重定向、www 与非 www 统一、移动端适配、页面加载速度、响应状态码检测。
3. robots.txt、sitemap 配置：是否正常生成、是否被搜索引擎抓取、有无屏蔽错误。
4. 标签优化检测：全站 TDK（标题、关键词、描述）是否规范、唯一、不重复、不堆砌，是否匹配核心业务关键词。
5. 图片 SEO 检测：图片 ALT 标签、图片压缩、图片链接合规性，是否存在无标注、失效图片问题。
6. 链接优化检测：内链布局合理性、外链质量、垃圾外链、无效内链排查，页面跳转异常检测。

模块 3：内容 SEO 诊断（核心排名维度）
1. 首页、栏目页、详情页内容质量：是否原创、是否同质化、是否空洞无价值、是否关键词布局缺失。
2. 信息一致性排查：官网所有页面的企业介绍、业务范围、资质信息、联系方式、成立时间是否统一，无前后矛盾、无新旧信息混杂。
3. 关键词布局排查：核心词、长尾词、地域词布局是否合理，是否堆砌、是否缺失核心流量词。
4. 更新机制排查：官网新闻、案例、动态板块是否长期不更新、内容陈旧、重复发布。
5. 合规性排查：是否存在虚假宣传、资质过期、文案违规、侵权内容、过期活动信息。

模块 4：全网联动一致性诊断（解决大模型误判核心）
1. 以官网为权威基准，全网检索企业在自媒体、B2B 平台、地图、媒体稿件、商铺页面的信息，排查与官网标准信息冲突、不统一、错误的内容。
2. 检测官网是否存在旧版本残留信息、历史错误文案、未清理的过期内容。
3. 排查全网是否存在多条冲突企业信息，导致搜索引擎、大模型无法识别权威主体。

模块 5：Schema.org 结构化数据诊断（GEO 核心技术手段）
1. 结构化数据覆盖检测：官网是否部署 Schema.org JSON-LD 结构化数据，覆盖哪些实体类型（Organization/LocalBusiness/Product/Service/FAQPage/Article/BreadcrumbList 等），是否存在缺失或类型错误。
2. 实体属性完整性检测：结构化数据中的企业名称、地址、电话、官网、Logo、联系方式、营业时间、价格区间等属性是否与官方标准信息一致，是否存在属性缺失、值不匹配、格式不规范问题。
3. 行业专属实体类型检测：根据企业所属行业，检测是否部署了行业专属 Schema.org 类型（如医疗 MedicalOrganization/Physician、金融 FinancialService、餐饮 Restaurant、教育 EducationalOrganization 等），以及行业核心属性（如医疗的 medicalLicenseNumber、金融的 license 等）是否正确映射。
4. 结构化数据语法验证：JSON-LD 是否语法正确、可被 Google Rich Results Test 和 Schema.org Validator 正确解析，是否存在嵌套错误、重复定义、属性值类型不匹配等技术问题。
5. AI 可提取性评估：评估结构化数据对 AI 大模型实体识别的实际增益，检测是否存在阻碍 AI 理解企业实体的结构化数据缺陷。

模块 6：AI 可爬取性检测（大模型收录友好度专项）
1. robots.txt AI 爬虫规则检测：检测官网 robots.txt 是否屏蔽了主流 AI 爬虫（GPTBot、OAI-SearchBot、ClaudeBot、PerplexityBot、CCBot、Google-Extended 等），是否存在误屏蔽导致 AI 无法抓取官网内容。
2. HTML 语义化检测：官网是否使用语义化 HTML 标签（header/nav/main/article/section/aside/footer），是否存在 div 滥用导致 AI 难以理解页面结构，是否使用 schema.org 微数据标注。
3. 内容可提取性检测：官网正文内容是否可被 AI 爬虫有效提取，是否存在 JavaScript 动态渲染导致爬虫无法获取内容、是否有关键内容仅在图片中（无文字版本）、是否存在登录墙/付费墙阻碍内容抓取。
4. 页面加载速度与可访问性：Core Web Vitals 指标（LCP/FID/CLS）是否达标，是否存在影响爬虫抓取效率的性能瓶颈。
5. AI 友好度综合评估：综合评估官网对 AI 大模型的信息可获取性、结构可理解性、实体可识别性，给出 AI 收录友好度评分与优化方向。

问题风险等级划分标准：
1. 一级致命风险（立即整改）：直接影响收录、GEO 定位、主体识别、排名暴跌。包含：NAP 核心信息错误、域名收录异常、死链泛滥、TDK 违规堆砌、地址/电话失效、地域定位错误、资质信息虚假、robots.txt 屏蔽 AI 爬虫、Schema.org 完全缺失或类型严重错误。
2. 二级重要风险（7 日内整改）：影响关键词排名、流量、本地权重、AI 画像精准度。包含：关键词布局缺失、内容同质化、内链混乱、页面加载缓慢、地域关键词缺失、话术不统一、Schema.org 属性缺失或不一致、HTML 语义化不足、关键内容仅图片呈现。
3. 三级优化风险（月度常态化整改）：不影响核心权重，影响整体质感与长期排名。包含：标点不规范、语句微调、图片无 ALT 标签、内容更新不及时、轻微话术差异、结构化数据微调。
