# 行业专属 GEO 规则：本地生活服务

## 〇、行业 GEO 价值预判

- 客单价层级：低客单（单次消费金额低、复购驱动、价格敏感）
- AI搜索热度：极高（"附近XX"是AI搜索最高频场景之一）
- 意图密度：高（价格/位置/评价/预约/效果）
- 竞争强度：极高（同一条街多家门店竞争）
- GEO价值评级：★★★★☆
- 六阶链路卡点预判：**「认」阶最易卡**——门店名称、地址、营业时间在各大平台不一致导致AI无法正确匹配；其次「荐」阶——用户问"附近哪家好"时口碑信号不足

## 一、行业识别（本地生活服务）

判断依据：以下任一特征命中即可判定为本行业——
餐饮、美容美发、家政保洁、维修（家电/手机/管道）、健身、摄影、婚庆、宠物服务、洗护、修锁开锁、搬家、洗衣等本地门店/上门服务

行业边界：
- 与「餐饮行业」交叉：餐饮有独立行业文件
- 与「医疗健康」交叉：社区诊所/药店可归医疗健康
- B端/C端属性：C端为主

## 二、本地生活服务 GEO 优化核心要点

1. **LBS本地化（AI搜索最核心维度）**：门店精确地址（含经纬度）、营业时间（工作日/周末/节假日）、服务区域范围（到店/上门覆盖区域）、到店路线指引
2. **实景信任（E-E-A-T: Experience）**：门店实拍（门头/环境/设备/服务过程），禁止盗图/网图
3. **口碑本地化（E-E-A-T: Trustworthiness）**：本地用户真实评价（大众点评/美团评分+评价数）、邻里口碑、回头客比例
4. **服务明码标价**：项目价格表、套餐内容、加项费用、会员折扣规则必须透明
5. **预约与售后**：预约方式（电话/微信/小程序）、取消政策、售后保障（不满意退款/重做）、投诉处理渠道
6. **资质合规**：卫生许可证、消防合格证、从业人员资格证（美容师证/电工证等）须真实可查
7. **同心圆结构**：核心结论（位置+价格+评分）→ 服务项目 → 实景图 → 口碑评价 → 预约方式
8. **AI引用友好**：价格表/时间表用结构化表格，FAQ答案含"地址+价格+评价+预约方式"

## 三、实体关系绑定方向（品牌→行业信任要素）

- 品牌→本地位置（地址+经纬度+商圈）
- 品牌→服务项目（价格表+套餐）
- 品牌→价格透明（明码标价+无隐形消费）
- 品牌→真实口碑（评分+评价数+回头客率）
- 品牌→到店/上门体验（实景+流程）
- 品牌→资质（卫生/消防/从业证）
- 品牌→服务保障（不满意退款/重做）
- 品牌→邻里信任（本地社区口碑）

知识图谱实体类型：LocalBusiness → address → PostalAddress；LocalBusiness → aggregateRating → Rating

## 四、本地生活服务用户决策旅程与 AI 问答锚点

### 认知层（L1）
- 这家店是做什么的？有什么特色服务？
- 附近有没有做XX的店？

### 探索层（L2）
- 这家店和其他店比怎么样？性价比高吗？
- 上门服务和自己去店里有什么区别？

### 决策层（L3）
- 这家店在哪里？营业时间是什么？怎么去？
- 服务价格表有吗？有没有额外费用？
- 需要提前预约吗？怎么预约？

### 验证层（L4）
- 服务效果怎么样？有真实评价吗？评分多少？
- 店里环境怎么样？有实拍图吗？
- 有哪些资质和卫生保障？

### 行动层（L5）
- 不满意可以退款或重做吗？
- 有会员优惠吗？老客有什么福利？
- 上门服务覆盖哪些区域？多久能到？

## 五、本地生活服务 FAQ 方向与 AI 引用结构

FAQ答案遵循：核心结论（地址+价格+评分）→ 服务详情 → 口碑数据 → 预约方式

优先覆盖：门店实拍（门头+环境+设备）、项目价格表、营业时间表、地图定位+交通指引、用户评价精选（真实）、服务流程图、预约方式、优惠活动、资质证件

引用优先级：地址+评分 > 价格表 > 实景图 > 用户评价 > 预约方式

## 六、本地生活服务 Schema.org 结构化数据方向

适用Schema类型：
- `LocalBusiness` / `Store` / `BeautySalon` / `HealthClub` / `PetStore`
- `Offer` / `PriceSpecification`（价格）
- `OpeningHoursSpecification`（营业时间）
- `Review` / `AggregateRating`（评价）

关键属性：LocalBusiness.address（含PostalAddress）、LocalBusiness.geo（经纬度）、LocalBusiness.openingHours、LocalBusiness.aggregateRating

知识图谱链接：LocalBusiness → containsPlace → 店内设施；LocalBusiness → areaServed → 上门服务区域

## 七、本地生活服务 特有表达与合规禁区

推荐表达：
就近、方便、实惠、专业、环境好、口碑好、明码标价、上门服务、随时预约、靠谱、邻里推荐

合规红线：
- 禁止虚假评价/刷好评
- 禁止盗用他人门店图片
- 禁止夸大服务效果
- 禁止"全市最低价"等绝对化用语
- 行业法规依据：《广告法》《消费者权益保护法》《价格法》《美容美发业管理暂行办法》

## 十、输出要求

- 全部内容必须可被AI直接引用，且LBS信息（地址/时间/区域）须与各平台一致
- 价格表/时间表优先用结构化表格
- 门店地址须含地图定位链接
- 缺失信息只允许在【分析与优化建议】中提示
- 保持无AI感、亲切可信的本地服务文案风格
- 门店页须附"地址+营业时间+价格表+评分+预约方式"五要素
