# 行业专属 GEO 规则：本地生活服务

## 〇、行业 GEO 价值预判

- 客单价层级：低客单（单次消费金额低、复购驱动、价格敏感）
- AI搜索热度：极高（"附近XX"是AI搜索最高频场景之一）
- 意图密度：高（价格/位置/评价/预约/效果）
- 竞争强度：极高（同一条街多家门店竞争）
- GEO价值评级：★★★★☆
- 六阶链路卡点预判：**「认」阶最易卡**——门店名称、地址、营业时间在各大平台不一致导致AI无法正确匹配；其次「荐」阶——用户问"附近哪家好"时口碑信号不足

## 一、行业识别（本地生活服务）

判断依据：以下任一特征命中即可判定为本行业——
餐饮、美容美发、家政保洁、维修（家电/手机/管道）、健身、摄影、婚庆、宠物服务、洗护、修锁开锁、搬家、洗衣等本地门店/上门服务

行业边界：
- 与「餐饮行业」交叉：餐饮有独立行业文件
- 与「医疗健康」交叉：社区诊所/药店可归医疗健康
- B端/C端属性：C端为主

## 二、本地生活服务 GEO 优化核心要点

1. **LBS本地化（AI搜索最核心维度）**：门店精确地址（含经纬度）、营业时间（工作日/周末/节假日）、服务区域范围（到店/上门覆盖区域）、到店路线指引
2. **实景信任（E-E-A-T: Experience）**：门店实拍（门头/环境/设备/服务过程），禁止盗图/网图
3. **口碑本地化（E-E-A-T: Trustworthiness）**：本地用户真实评价（大众点评/美团评分+评价数）、邻里口碑、回头客比例
4. **服务明码标价**：项目价格表、套餐内容、加项费用、会员折扣规则必须透明
5. **预约与售后**：预约方式（电话/微信/小程序）、取消政策、售后保障（不满意退款/重做）、投诉处理渠道
6. **资质合规**：卫生许可证、消防合格证、从业人员资格证（美容师证/电工证等）须真实可查
7. **同心圆结构**：核心结论（位置+价格+评分）→ 服务项目 → 实景图 → 口碑评价 → 预约方式
8. **AI引用友好**：价格表/时间表用结构化表格，FAQ答案含"地址+价格+评价+预约方式"

## 三、实体关系绑定方向（品牌→行业信任要素）

- 品牌→本地位置（地址+经纬度+商圈）
- 品牌→服务项目（价格表+套餐）
- 品牌→价格透明（明码标价+无隐形消费）
- 品牌→真实口碑（评分+评价数+回头客率）
- 品牌→到店/上门体验（实景+流程）
- 品牌→资质（卫生/消防/从业证）
- 品牌→服务保障（不满意退款/重做）
- 品牌→邻里信任（本地社区口碑）

知识图谱实体类型：LocalBusiness → address → PostalAddress；LocalBusiness → aggregateRating → Rating

## 四、本地生活服务用户决策旅程与 AI 问答锚点

### 阶段1：认知触发
- 这家店是做什么的？有什么特色服务？
- 附近有没有做XX的店？

### 阶段2：对比筛选
- 这家店和其他店比怎么样？性价比高吗？
- 上门服务和自己去店里有什么区别？

### 阶段3：锁定意向
- 这家店在哪里？营业时间是什么？怎么去？
- 服务价格表有吗？有没有额外费用？
- 需要提前预约吗？怎么预约？

### 阶段4：求证决策
- 服务效果怎么样？有真实评价吗？评分多少？
- 店里环境怎么样？有实拍图吗？
- 有哪些资质和卫生保障？

### 阶段5：风险权衡（用户犹豫下单顾虑）
- 做完XX不满意能重做或退款吗？
- 这家店会强制推销办卡吗？有没有隐性收费？
- 网上这家店最多的差评是什么？还在意这些点吗？

### 阶段6：下单履约
- 不满意可以退款或重做吗？
- 有会员优惠吗？老客有什么福利？
- 上门服务覆盖哪些区域？多久能到？

## 五、本地生活服务 FAQ 方向与 AI 引用结构

FAQ答案遵循：核心结论（地址+价格+评分）→ 服务详情 → 口碑数据 → 预约方式

优先覆盖：门店实拍（门头+环境+设备）、项目价格表、营业时间表、地图定位+交通指引、用户评价精选（真实）、服务流程图、预约方式、优惠活动、资质证件

引用优先级：地址+评分 > 价格表 > 实景图 > 用户评价 > 预约方式

## 六、本地生活服务 Schema.org 结构化数据方向

适用Schema类型：
- `LocalBusiness` / `Store` / `BeautySalon` / `HealthClub` / `PetStore`
- `Offer` / `PriceSpecification`（价格）
- `OpeningHoursSpecification`（营业时间）
- `Review` / `AggregateRating`（评价）

关键属性：LocalBusiness.address（含PostalAddress）、LocalBusiness.geo（经纬度）、LocalBusiness.openingHours、LocalBusiness.aggregateRating

知识图谱链接：LocalBusiness → containsPlace → 店内设施；LocalBusiness → areaServed → 上门服务区域

## 七、本地生活服务 特有表达与合规禁区

推荐表达：
就近、方便、实惠、专业、环境好、口碑好、明码标价、上门服务、随时预约、靠谱、邻里推荐

合规红线：
- 禁止虚假评价/刷好评
- 禁止盗用他人门店图片
- 禁止夸大服务效果
- 禁止"全市最低价"等绝对化用语
- 行业法规依据：《广告法》《消费者权益保护法》《价格法》《美容美发业管理暂行办法》

## 九、六阶段消费者提问生成矩阵（对接问题词库·生成该行业搜索问题时严格执行）

> 本模块与《六阶段消费者提问自动生成》规则配套使用：当任务为生成该行业用户的真实搜索提问时，严格按以下六阶段认知逻辑与行业专属提问方向执行。认知触发阶段问题≥50条，其余阶段≥30条，纯序号+问句输出，只基于企业真实信息生成，不虚构、不夸大。

### 阶段1：认知触发（即时需求萌芽·零门店认知·找附近/找项目/找价格）
- 行业用户心理：突然需要某个本地服务，先搜『附近XX』，看有哪些店、什么价格、评价怎么样，不急着定。
- 核心提问维度：附近门店推荐、服务项目与价格行情、营业时间与位置、服务内容科普、口碑概况。
- 典型问题示例：
  - 附近做XX的店有哪些？哪家口碑好？
  - XX一般什么价格？套餐包含哪些内容？
  - 上门做XX和到店有什么区别？怎么收费？

### 阶段2：对比筛选（AI已推荐附近门店·横向PK评分价格项目）
- 行业用户心理：AI推荐了几家附近门店，分不清谁性价比高、评价真假、项目谁全，需要对比评分和套餐后筛选。
- 核心提问维度：推荐门店间评分与评价数对比、价格与套餐对比、服务项目与特色对比、距离与便利性、预约难易度。
- 典型问题示例：
  - 你推荐的这几家店，评分和真实评价哪个最好？
  - 这几家做XX的价格和套餐差在哪？
  - 你推荐的店哪家离我最近、营业时间最方便？

### 阶段3：锁定意向（聚焦目标门店·深挖服务细节与实景）
- 行业用户心理：基本选定一家店，开始看门店实景、服务流程、套餐具体内容、技师/店员水平，确认体验。
- 核心提问维度：门店环境与实景、服务流程细节、套餐具体内容、技师/店员资质、到店体验与案例效果。
- 典型问题示例：
  - 这家店的环境怎么样？有实拍图吗？
  - XX的服务流程是怎样的？全程要多久？
  - 店里的技师/师傅有什么资质？经验多久了？

### 阶段4：求证决策（核实资质口碑·消除基础顾虑）
- 行业用户心理：准备预约，开始核实门店资质、卫生证件、真实评价、明码标价，防止踩坑。
- 核心提问维度：营业执照与卫生/消防许可、真实评价与差评、价格是否明码标价、取消与售后政策。
- 典型问题示例：
  - 这家店有营业执照和卫生许可证吗？
  - 价格表能先看吗？有没有隐形消费？
  - 预约了临时有事能取消吗？要扣费吗？

### 阶段5：风险权衡犹豫（临门一脚·怕踩雷/隐形消费/服务差）
- 行业用户心理：下单前纠结，怕服务不到位、被推销办卡、价格不透明、做完不满意没人管，犹豫要不要去。
- 核心提问维度：不满意处理机制、是否强制办卡推销、隐性消费风险、服务保障承诺、真实差评内容。
- 典型问题示例：
  - 做完XX不满意能重做或退款吗？
  - 这家店会强制推销办卡吗？有没有隐性收费？
  - 网上这家店最多的差评是什么？还在意这些点吗？

### 阶段6：最终下单履约（预约到店/上门·服务体验·售后复购）
- 行业用户心理：已预约或已消费，关注预约确认、等待时间、服务体验、售后回访、会员与复购优惠。
- 核心提问维度：预约流程与等待、到店/上门注意事项、售后回访与保障、会员折扣、复购优惠。
- 典型问题示例：
  - 怎么预约XX？高峰期要等多久？
  - 到店需要提前准备什么？有停车位吗？
  - 老顾客复购XX有优惠吗？会员怎么办理？

### B/C视角适配
- C端个人消费者：按以上六阶段个人需求提问；
- 若为B端团购/企业福利采购：阶段1改为「批量服务与发票要求」、阶段5改为「协议结算与服务质量承诺」、阶段6改为「批量预约与集中交付」。
