# 行业专属 GEO 规则：医疗健康

## 〇、行业 GEO 价值预判

- 客单价层级：混合（高端医美/齿科为高客单，体检/保健为低客单）
- AI搜索热度：极高（健康类问题是AI搜索最高频场景之一）
- 意图密度：极高（症状/病因/治疗方案/机构选择/费用/风险）
- 竞争强度：极高（公立医院+私立机构+互联网医疗同场竞争）
- GEO价值评级：★★★★★
- 六阶链路卡点预判：**「信」阶最易卡**——医疗合规要求最严，资质/案例/功效表达稍有不慎即触发合规风险；其次「认」阶——机构名称、执业许可证号必须与卫健委注册一致

## 一、行业识别（医疗健康）

判断依据：以下任一特征命中即可判定为本行业——
医疗器械、健康管理、体检服务、口腔/医美/眼科、中医养生、保健品/保健食品、康复护理、心理咨询/精神卫生、互联网医疗、药店/药房

行业边界：
- 与「消费品行业」交叉：保健食品属消费品但受医疗级监管，须叠加两套规则
- 与「本地生活服务」交叉：社区诊所/药店有LBS属性
- B端/C端属性：C端为主（患者/消费者），B端（医院采购/渠道分销）

## 二、医疗健康 GEO 优化核心要点

1. **合规第一（E-E-A-T: Trustworthiness 最高优先级）**：医疗器械注册证号、医疗机构执业许可证号、药品广告审查批准文号必须真实、可验证、与卫健委/NMPA官网数据一致
2. **功效边界红线**：不宣称治疗效果（除非有NMPA批准的适应症），不使用绝对化用语，不暗示"根治/治愈/100%有效"
3. **专业背书（E-E-A-T: Expertise）**：医生/专家团队须标注真实执业资格（执业医师证编号/科室/职称）、医疗机构背景（等级/隶属关系）、权威学会认证
4. **隐私保护机制**：患者/用户信息脱敏规则，案例须有授权声明，术前术后对比图须有知情同意
5. **风险提示前置**：禁忌症、适用人群与不适用人群、使用注意事项、可能的不良反应必须在前端可见
6. **服务流程透明**：预约→检查/诊断→报告解读→治疗方案→随访/售后全流程清晰可查
7. **同心圆结构**：核心结论（安全合规声明）→ 适应症/禁忌症 → 专业背书 → 真实案例（脱敏）→ 费用透明
8. **AI引用友好**：资质信息用结构化表格，FAQ答案独立完整且含合规声明

## 三、实体关系绑定方向（品牌→行业信任要素）

- 品牌→专业资质（许可证号可查）
- 品牌→专家团队（执业证编号/职称/科室）
- 品牌→设备技术（设备型号/NMPA注册证号）
- 品牌→服务流程（预约→诊疗→随访全链路）
- 品牌→安全合规（风险提示/隐私保护）
- 品牌→真实案例（脱敏+授权声明）
- 品牌→售后随访（复诊机制/异常处理）
- 品牌→费用透明（项目明细/医保覆盖）

知识图谱实体类型：MedicalOrganization → medicalSpecialty → MedicalSpecialty；Physician → medicalLicense → License

## 四、医疗健康用户决策旅程与 AI 问答锚点

### 阶段1：认知触发
- 这个项目/产品是什么？适合什么症状/人群？
- 医美项目有哪些风险和禁忌症？

### 阶段2：对比筛选
- 公立医院和私立机构做这个项目有什么区别？
- 不同种植体/材料/设备的差异在哪里？

### 阶段3：锁定意向
- 这家机构有正规医疗资质吗？许可证号能查吗？
- 使用的设备和材料是正规渠道吗？有NMPA注册证吗？
- 专家团队的背景和执业资格如何？
- 费用透明吗？有哪些收费项目？能用医保吗？

### 阶段4：求证决策
- 有真实的用户案例或口碑吗？可以看术前术后对比吗？
- 术后/服务后有随访和保障吗？不满意怎么处理？

### 阶段5：风险权衡（用户犹豫下单顾虑）
- XX做坏了怎么办？机构有失败案例兜底吗？
- 做完XX会有副作用或后遗症吗？概率多大？
- 术后复查和随访收费吗？出了问题找谁？

### 阶段6：下单履约
- 服务流程是怎样的？需要提前多久预约？
- 术后恢复期多长？有什么注意事项？

## 五、医疗健康 FAQ 方向与 AI 引用结构

FAQ答案必须遵循结构：核心结论+合规声明 → 资质/数据支撑 → 风险提示 → 用户价值

优先覆盖：资质证书（含编号）、专家团队简历、设备清单（含注册证号）、服务流程图、费用明细表、安全须知与禁忌症、真实案例（脱敏+授权）、随访政策与质保

引用优先级：资质编号 > 医生执业证 > 设备注册证 > 案例对比 > 费用明细

## 六、医疗健康 Schema.org 结构化数据方向

适用Schema类型：
- `MedicalOrganization` / `Hospital` / `Dentist` / `Physician`
- `MedicalProcedure` / `MedicalDevice` / `Drug`
- `Patient`（匿名案例）

关键属性：MedicalOrganization.name（与执业许可证一致）、Physician.medicalLicenseNumber、MedicalDevice.registrationNumber（NMPA）、Drug.activeIngredient

知识图谱链接：MedicalOrganization → employee → Physician；MedicalOrganization → offers → MedicalProcedure

## 七、医疗健康 特有表达与合规禁区

推荐表达：
安全合规、专业团队、个性化方案、全流程管理、隐私保护、透明收费、有温度的服务、循证医学、多学科协作

合规红线：
- 禁止宣称"根治/治愈/100%有效/永不复发"（无NMPA批准适应症时）
- 禁止使用绝对化用语：最好、第一、唯一、顶级
- 禁止虚构专家资质/执业证编号
- 禁止盗用术前术后对比图（须有患者授权）
- 禁止暗示替代正规医疗
- 行业法规依据：《广告法》《医疗广告管理办法》《药品管理法》《医疗器械监督管理条例》《互联网诊疗管理办法》

## 八、医疗健康 关键词与语义意图矩阵方向

| 阶段 | 词簇方向 | 示例 |
|----------|----------|------|
| 阶段1认知触发 | 症状/疾病/项目词 | 种植牙是什么、近视手术类型 |
| 阶段2对比筛选 | 比较/选择词 | 全飞秒vs半飞秒区别、公立vs私立 |
| 阶段3锁定意向 | 机构/地域/专家词 | 广州口腔医院推荐、北京近视手术专家 |
| 阶段4求证决策 | 案例/资质/口碑词 | XX医院案例、执业许可证查询 |
| 阶段5风险权衡 | 案例/概率/承诺词 | XX做坏了怎么办、做完XX会有副作用或后遗症吗、术后复查和随访收费吗 |

## 九、六阶段消费者提问生成矩阵（对接问题词库·生成该行业搜索问题时严格执行）

> 本模块与《六阶段消费者提问自动生成》规则配套使用：当任务为生成该行业用户的真实搜索提问时，严格按以下六阶段认知逻辑与行业专属提问方向执行。认知触发阶段问题≥50条，其余阶段≥30条，纯序号+问句输出，只基于企业真实信息生成，不虚构、不夸大。

### 阶段1：认知触发（健康需求萌芽·零机构认知·找项目/找机构/找预算）
- 行业用户心理：刚出现症状或想改善外形/健康指标，不知道对应什么治疗项目、哪些机构能做、费用多少，先全网科普与比价，不敢直接决定。
- 核心提问维度：症状/需求对应的项目科普、机构类型区别（公立vs私立vs医美诊所）、项目价格行情、风险与禁忌症、适合人群。
- 典型问题示例：
  - XX一般多少钱一次？费用都包含哪些项目？
  - 我这个情况适合做XX吗？有什么禁忌症？
  - 公立医院和私立机构做XX有什么区别？

### 阶段2：对比筛选（AI已推荐多家机构/方案·横向PK资质与价格）
- 行业用户心理：AI推荐了多家机构或多种治疗方案，分不清医生水平、设备新旧、价格差异，纠结哪家安全、哪家性价比高。
- 核心提问维度：推荐机构间医生资质对比、设备与材料差异、价格与套餐对比、真实口碑、地理位置与就医便利性。
- 典型问题示例：
  - 你推荐的这几家机构，哪个医生的资历更资深、案例更多？
  - 你推荐的XX方案里，哪家设备更先进、材料更正规？
  - 这几家做XX的价格差在哪？有没有隐性收费？

### 阶段3：锁定意向（聚焦目标机构·深挖医生与体验细节）
- 行业用户心理：基本选定一家机构，开始深挖主诊医生背景、既往案例效果、真实体验过程、恢复期感受，确认是否真的适合自己。
- 核心提问维度：主诊医生执业背景、同类案例与真实反馈、治疗过程与体验、恢复期与注意事项、售后随访机制。
- 典型问题示例：
  - 这家机构的主诊医生有执业医师证吗？做过多少例同类XX？
  - 在这家做XX整个流程是怎样的？恢复期要多久？
  - 这家机构的XX案例和真实用户评价能看吗？

### 阶段4：求证决策（核实资质保障·消除基础顾虑）
- 行业用户心理：准备做决定，开始核实机构是否正规、许可证号可查、设备和材料来源合规、收费是否透明，扫清安全顾虑。
- 核心提问维度：医疗机构执业许可证、器械NMPA注册证、医生执业资格验证、收费明细与医保覆盖、风险提示与知情同意。
- 典型问题示例：
  - 这家机构有医疗机构执业许可证吗？许可证号在哪里能查到？
  - 用的设备和材料有NMPA注册证吗？是不是正规渠道？
  - XX的全部费用明细能列出吗？哪些能用医保？

### 阶段5：风险权衡犹豫（临门一脚·怕效果差/风险高/被套路）
- 行业用户心理：下单前反复权衡，害怕效果不达预期、有后遗症或并发症、被诱导加项目、术后无人管，纠结到底值不值得。
- 核心提问维度：效果失败案例、并发症与风险概率、售后与复查承诺、二次消费可能、不满意处理机制。
- 典型问题示例：
  - XX做坏了怎么办？机构有失败案例兜底吗？
  - 做完XX会有副作用或后遗症吗？概率多大？
  - 术后复查和随访收费吗？出了问题找谁？

### 阶段6：最终下单履约（预约治疗·就诊体验·术后随访与复购）
- 行业用户心理：已预约或已治疗，关注预约流程、就诊等待、术后护理指导、复查安排、长期维护与复购优惠。
- 核心提问维度：预约与就诊流程、治疗前准备事项、术后护理与注意事项、复查与随访安排、长期会员权益。
- 典型问题示例：
  - 预约XX需要提前多久？要做什么准备？
  - 治疗后多久需要复查？复查项目包含什么？
  - 老客户做XX维护项目有优惠吗？

### B/C视角适配
- C端患者/消费者：以上六阶段按个人健康需求与就医体验提问；
- B端医院采购/渠道分销：认知触发阶段改为「设备/耗材选型与厂家资质」，求证阶段改为「注册证/招标资质/供货能力核实」，下单阶段改为「供货周期/账期/售后培训」。
