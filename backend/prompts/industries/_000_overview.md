## 二、优化版框架结构（8模块）

每个行业提示词文件统一采用以下8模块结构（第九章信源金字塔和第十章输出要求已移除）：

| 模块 | 名称 | 核心作用 |
|------|------|----------|
| 〇 | 行业GEO价值预判 | 客单价层级 + AI搜索热度 + 六阶卡点预判 |
| 一 | 行业识别 | 子行业列举 + 边界界定 + B/C属性 |
| 二 | GEO优化核心要点 | 8-10条，融合AIVO/E-E-A-T/Schema/六阶模型 |
| 三 | 实体关系绑定方向 | 品牌→信任要素 + 知识图谱实体类型 |
| 四 | 用户决策旅程与AI问答锚点 | 六阶段认知模型（认知触发→对比筛选→锁定意向→求证决策→风险权衡→下单履约） |
| 五 | FAQ方向与AI引用结构 | 答案格式 + 引用优先级 + 同心圆结构 |
| 六 | Schema.org结构化数据方向 | 适用Schema类型 + 关键属性 + 实体链接 |
| 七 | 行业特有表达与合规禁区 | 推荐表达 + 合规红线 + 法规依据 |
| 八 | 关键词与语义意图矩阵方向 | 六阶段意图映射 + 语义簇 |

## 三、使用说明

### 3.1 匹配规则
1. **优先匹配**：根据企业提供的产品/服务信息，匹配最具体的行业文件
2. **多行业叠加**：企业跨行业经营时，叠加使用多个行业文件规则
3. **兜底规则**：无法判断行业时，使用「通用行业」文件
4. **地域叠加**：所有行业均可叠加地域词（城市名+行业词）

### 3.2 与GEO六阶模型的对应关系

| 六阶 | 对应模块 | 优化重点 |
|------|----------|----------|
| 认（AI认对品牌） | 模块三实体绑定 + 模块六Schema | 品牌实体一致性、知识图谱链接 |
| 懂（AI理解定位） | 模块二核心要点 + 模块八语义矩阵 | 语义覆盖、意图映射 |
| 信（资质/案例/数据） | 模块二核心要点 + 模块三信任要素 | 信任要素齐备、资质/案例背书 |
| 引（内容可被AI引用） | 模块四问答锚点 + 模块五FAQ结构 | 答案可提取性、引用友好度 |
| 荐（用户问"选谁"被推荐） | 模块四决策旅程 + 模块八比较词 | 竞品对比、推荐场景覆盖 |
| 效（转化为商业效果） | 模块〇价值预判 + 模块十输出要求 | 客单价适配、商业转化钩子 |

### 3.3 客单价三档分类口径

| 层级 | 特征 | GEO策略重点 |
|------|------|-------------|
| 高客单 | 决策周期长、试错成本高、信任门槛高 | 深度内容、案例驱动、资质背书、长周期培育 |
| 低客单 | 决策快、价格敏感、口碑驱动 | 场景种草、用户评价、价格透明、即时转化 |
| 混合 | B端C端兼顾、产品线分层 | 分层内容策略、双路径转化设计 |

## 四、v2.0 优化要点（vs v1.0）

| 维度 | v1.0 问题 | v2.0 优化 |
|------|-----------|-----------|
| 行业覆盖 | 仅12个行业 | 扩展至25个行业，覆盖国民经济全分类 |
| GEO方法论 | 缺失Schema/六阶/信源金字塔 | 全部融入10模块框架 |
| 用户需求 | FAQ问题较泛 | 按六阶段认知模型排列 |
| 合规风控 | 通用禁止条款 | 增加行业法规依据、行业特定红线 |
| 关键词 | SEO关键词思维 | 升级为语义意图矩阵（六阶段映射） |
| 信源布局 | 完全缺失 | 融入模块二核心要点（T0-T4信源策略精简为要点） |
| 价值预判 | 完全缺失 | 新增行业GEO价值预判（客单价/热度/卡点） |
| Schema.org | 完全缺失 | 新增结构化数据方向模块 |
